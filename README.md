# منوی دیجیتال کافه اُلا · Ola Cafe

آدرس منو: https://z4hak.github.io/ola-cafe/

## تغییر قیمت‌ها
1. در همین صفحه روی فایل `menu.json` بزنید و آیکون مداد (Edit) را انتخاب کنید.
2. عدد جلوی `"p":` هر آیتم را عوض کنید (به هزار تومان). برای «قیمت روز» بنویسید `null`.
3. برای «تمام شد»، `"off": false` را به `"off": true` تغییر دهید.
4. پایین صفحه **Commit changes** را بزنید. بعد از یکی دو دقیقه منو به‌روز می‌شود و QR هم تغییری نمی‌کند.
